# Shopify Bundle Builder

A custom Shopify bundle builder that allows customers to create product sets through a guided selection process.

## Features

- Multi-step product selection
- Dynamic bundle summary
- Real-time price updates
- AJAX Add to Cart
- Responsive design
- Custom Shopify integration

## Tech Stack

- Shopify Liquid
- JavaScript
- CSS
- Shopify AJAX API
